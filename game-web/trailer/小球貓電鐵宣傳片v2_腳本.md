# 小球貓電鐵宣傳片 v2｜60 秒腳本與音樂 Cue

## 輸出規格

- 主版長度：60 秒
- 設計畫布：16:9（邏輯座標建議 1920 × 1080）
- 顯示方式：`contain`；等比例儘可能放大，超出比例的區域以黑色 letterbox／pillarbox 補齊
- 所有遊戲物件只使用設計畫布座標；不可直接以瀏覽器 viewport 定位
- 建議安全區：左右各 8%、上下各 7%；字幕與 Logo 不進入黑邊
- 音樂：120 BPM、4/4、30 小節；每小節 2 秒，場景切點全部對齊小節線

## 核心故事

從「選一隻貓，踏上台灣旅程」開始，依序讓觀眾看見探索、經營、卡片策略、交通捷徑、目的地慶祝與最終結算。重點不是列出所有功能，而是讓功能組成一趟越來越熱鬧的冒險。

## 剪輯與程式規則

1. 場景時間以音樂時間軸為唯一基準，不以連續累加的 `setTimeout` 推算。
2. 每段建立 `start / pause / resume / stop` 生命週期，切場時必須停止前一場的動畫與音效。
3. 地圖路線、骰子點數、目的地、新聞與排名使用固定資料，確保每次輸出完全一致。
4. 字幕每次最多兩行；主要句子至少保留 2.5 秒可讀時間。
5. BGM 保持一首連續作品；列車、骰子、交通工具等遊戲音效以短 cue 疊加，不在每場更換整首 BGM。
6. 00:38 的目的地揭曉及 00:50 的總決算是兩個主要情緒轉折，畫面剪點不得偏離音樂小節線。

## 發布前驗證

- 以 16:9、16:10、21:9、4:3 及直式視窗測試；設計畫布比例必須保持 16:9，僅黑邊尺寸改變。
- 至少驗證 1280×720、1920×1080、2560×1440、3840×2160；物件不得因解析度改變相對位置。
- 逐一核對 10 個場景切點：0、4、8、14、20、26、34、40、46、50、56、60 秒。
- 檢查主旋翼、尾旋翼與轉軸位置；起飛後靜態葉片不可殘留。
- 確認所有產品數字與功能文案均由目前遊戲資料驗證後再發布。
