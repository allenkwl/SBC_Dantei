# 小球貓電鐵｜總決算動畫版本紀錄

## 版號規則

- 每次修改都另存新 HTML，舊版不覆蓋。
- 目前最新版為 `總決算動畫模擬v1.1.html`。
- 下一次修改從 `v1.2` 開始，之後依序遞增。
- 各版共用的圖片、音效放在 `assets/`，既有素材不任意覆蓋；改圖時另存新版本檔名。

## 歷史版本

### v0.1

- 第一版總決算頒獎動畫。
- CSS 天空、山丘、城市與月台場景。
- 使用觀光列車，單次進站。
- 自適應滿版顯示。

### v0.2

- 改用載具測試的普通車（正式）。
- 加入水平鏡像、循環進出站與全螢幕啟動。
- 舞台固定為 4:3。

### v0.3

- 加入原創手繪水彩山城與車站背景。
- 保留 CSS 鐵軌與普通車（正式）。

### v0.4

- 鐵軌重畫為與背景一致的水彩風格。
- 頒獎台升級為進階金、銀、銅材質與冠軍光暈。

### v0.5

- 背景改為無雲、無右上樹枝的動畫底圖。
- 鐵軌縮為單軌。
- 加入透明樹枝葉片與多層慢速飄雲。
- 加入原創手繪雙節普通車套圖。

### v0.6

- `FINAL DESTINATION` 改用俐落窄體無襯線字。
- 移除英文眉標的文字陰影與外框陰影。
- 手繪普通車放大為 v0.5 的 2.5 倍，並重新對準鐵軌。

### v0.7

- 舞台比例改為 `1710 × 1107`，配合指定電腦全螢幕。
- 背景精準鋪滿舞台，不裁掉上方物件或底部鐵軌。
- 依新比例重新校正火車的輪軌高度。
- 金額改用「萬／億」中文單位顯示。

### v0.8

- 火車改為每 20 秒一班。
- 火車約 5 秒駛過畫面，駛離後在畫面外等待約 15 秒。

### v0.9

- 舞台改為**固定 1280 × 800 畫布**，整個用一次 `transform: scale()` 等比縮放置中（只縮不放大）。
  - 原因：原本尺寸靠 `aspect-ratio` 固定，但字級與面板寬度是用 `vw` 算的——那是跟著「視窗」而不是「舞台」變。視窗比例一改，舞台縮小、文字卻繼續長大，相對位置就跑掉。
  - 全檔 22 處 `vw / vh` 全部換成 1280 寬下的等值 px，改變視窗大小時相對座標完全不動。
- 修掉冠軍橫幅壓住主標題（標題整塊上移至 `top:8%`、主標題 60px、橫幅下移至 `top:27.5%`）。
- 金額面板加寬到 700px、數字改 60px，最長的「12 億 3,456 萬元」也是一行不斷行。
- 第 4 名小卡與右側明細上移至 `top:18.5%`，不再與頒獎台重疊；右側明細不再超出畫布。
- 左下角版本小字加上半透明底，壓在鐵軌上也讀得到。

### v1.0

- 改成**只固定比例、不固定解析度**：畫布尺寸改為 `1280 × 828.66`（＝ 1710:1107，跟背景圖原始比例一致，
  不再被拉伸），儘可能縮放到填滿視窗——取寬高比例中較小的那個，填滿一邊、另一邊留黑邊，
  不再限制「只能縮小不能放大」。
- 16:9（1920×1080）與較窄視窗（1024×1000）都測過：分別是左右留黑邊、上下留黑邊，
  畫面比例始終是 1710:1107。

### v1.1

- 加入「總決算慶祝」BGM（`assets/audio/finale.mp3`，已正規化到 -25.4dB，跟 `spring.mp3` 對齊），
  從動畫開始（含重播）就進場，全程循環播放。
- 冠軍揭曉、歡呼聲響起的那一刻讓 BGM 暫時讓路（duck 到 22%、1.6 秒後 700ms 內回到原音量），
  跟遊戲本體同一套避讓手法。
- 修正歡呼聲音量：`cheer.mp3` 素材本身已經正規化到 -27.2dB，跟遊戲其他音效的目標一致，
  舊的 `volume=.72` 反而讓它比目標小了約 3dB，改回 `1.0`。
