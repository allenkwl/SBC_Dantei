# 小球貓電鐵｜總決算動畫版本紀錄

## 版號規則

- 每次修改都另存新 HTML，舊版不覆蓋。
- 目前最新版為 `總決算動畫模擬v0.8.html`。
- 下一次修改從 `v0.9` 開始，之後依序遞增。
- 各版共用的圖片、音效放在 `assets/`，既有素材不任意覆蓋；改圖時另存新版本檔名。

## 歷史版本

### v0.1

- 第一版總決算頒獎動畫。
- CSS 天空、山丘、城市與月台場景。
- 使用觀光列車，單次進站。
- 自適應滿版顯示。

### v0.2

- 改用載具測試的普通車（正式）。
- 加入水平鏡像、循環進出站與全螢幕啟動。
- 舞台固定為 4:3。

### v0.3

- 加入原創手繪水彩山城與車站背景。
- 保留 CSS 鐵軌與普通車（正式）。

### v0.4

- 鐵軌重畫為與背景一致的水彩風格。
- 頒獎台升級為進階金、銀、銅材質與冠軍光暈。

### v0.5

- 背景改為無雲、無右上樹枝的動畫底圖。
- 鐵軌縮為單軌。
- 加入透明樹枝葉片與多層慢速飄雲。
- 加入原創手繪雙節普通車套圖。

### v0.6

- `FINAL DESTINATION` 改用俐落窄體無襯線字。
- 移除英文眉標的文字陰影與外框陰影。
- 手繪普通車放大為 v0.5 的 2.5 倍，並重新對準鐵軌。

### v0.7

- 舞台比例改為 `1710 × 1107`，配合指定電腦全螢幕。
- 背景精準鋪滿舞台，不裁掉上方物件或底部鐵軌。
- 依新比例重新校正火車的輪軌高度。
- 金額改用「萬／億」中文單位顯示。

### v0.8

- 火車改為每 20 秒一班。
- 火車約 5 秒駛過畫面，駛離後在畫面外等待約 15 秒。
