# 劇場版到站列車 v0.1

供 `game-web/目的地慶祝動畫模擬v1.8.html` 使用的四款手繪列車素材。

- `慢車.png`：紅色蒸汽火車頭
- `快車.png`：銀色綠線通勤電車
- `普悠瑪.png`：紅白流線型自強號，車側保留可辨識的紅色手寫體 `TRA`
- `高鐵.png`：白橘高速列車

圖像以原本四款正式列車為造型參考，統一重繪為溫暖水彩、細緻手繪線條與劇場動畫質感。透明 PNG 僅先套用於 v1.8 模擬程式，未覆蓋正式遊戲舊圖。

快車與普悠瑪保留方形透明畫布，讓模擬程式可以沿用正式遊戲既有的寬度、`right` 與 `bottom` 停靠參數；慢車與高鐵則維持原車圖的橫幅比例。
